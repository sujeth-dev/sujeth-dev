## About Me

Software engineering student in Bengaluru who ships production systems end to end — from database schema to deployment pipeline. I build things that handle **real money**, **real users**, and **real failure modes**.

What I care about most is the gap between _"works on my machine"_ and _"works in production."_ That gap is where the interesting engineering lives — idempotent webhooks, zero-downtime migrations, permission scoping, race condition guards.

- Currently building: **Loyalty platform**, **Adaptive learning platform**, **B2B application**
- Currently exploring: **AI Agents** and **System Design Patterns**
- Education: **B.Tech. AIML** @ UVCE, Bengaluru (2023 – 2027)
- Ask me about: **React, Next.js, TypeScript, Supabase, Production Engineering**
